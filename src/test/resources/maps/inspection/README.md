These unmodified built-in maps are from the official Mindustry v160 server-release.jar (Anuken/Mindustry, GPL-3.0). Source: https://github.com/Anuken/Mindustry/tree/v160/core/assets/maps/default

Tests decode these files into detached snapshots. They never load them into the test world. Small adversarial and per-finding maps are generated by MsavFixture directly from wire values.

`bundled-v160.zip` contains every one of the 114 unmodified `.msav` files in
`core/assets/maps` from the official `v160` tag, commit
`0ac15152d881f77dd4566a13c8d5f1225aee1068`, read from the sibling Git object database.
Source: https://github.com/Anuken/Mindustry/tree/v160/core/assets/maps
The ZIP uses stored entries in path order with fixed timestamps, preserving the
original compressed map bytes. ZIP SHA-256:
`7b0d70aeb2bedc8a2a1ae734a62e36bae5f3a7baadb69cbf642c925ba4c9fba8`.

`BundledMsavInspectionTest` checks all 114 files: 111 decode and run both inferred
and Tower Defence checks; `default/canyon.msav` is explicitly rejected for ambiguous
unknown legacy block framing, and `serpulo/hidden/242.msav` plus
`serpulo/littoralShipyard.msav` are explicitly rejected for gameplay patches.
The corpus covers save versions 2, 4, 5, 7, 8, 11 and 13. Generated fixtures cover
every version from 1 through 13 and all 24 v160 build-plan config wire types.
